Voici une mini-fiche des commandes de base du terminal 👇

## 🗂️ Se déplacer & voir les fichiers

| Commande | Ce que ça fait | Exemple |
|----------|----------------|---------|
| `pwd` | Affiche où tu es (dossier actuel) | `pwd` |
| `ls` | Liste les fichiers du dossier | `ls` |
| `ls -la` | Liste **tout** (fichiers cachés + détails) | `ls -la` |
| `cd` | Entre dans un dossier | `cd Documents` |
| `cd ..` | Remonte d'un dossier | `cd ..` |
| `cd ~` | Retour au dossier maison | `cd ~` |
| `cat` | Affiche le contenu d'un fichier | `cat notes.txt` |

## 📁 Manipuler fichiers & dossiers

| Commande | Ce que ça fait | Exemple |
|----------|----------------|---------|
| `mkdir` | Crée un dossier | `mkdir projet` |
| `touch` | Crée un fichier vide | `touch todo.txt` |
| `cp` | Copie | `cp a.txt b.txt` |
| `mv` | Déplace ou renomme | `mv a.txt dossier/` |
| `rm` | Supprime un fichier ⚠️ | `rm vieux.txt` |
| `open .` | Ouvre le dossier dans le Finder (Mac) | `open .` |

## 🤖 Claude Code dans le terminal

| Action | Comment |
|--------|---------|
| Lancer Claude | tape `claude` |
| Lui parler | écris ta demande en français, `Entrée` |
| Quitter | `/exit` ou `Ctrl + C` |
| Voir les commandes | `/help` |
| Effacer la conversation | `/clear` |

## 💡 3 astuces
- **`Tab`** = complète automatiquement les noms de fichiers/dossiers.
- **`↑`** (flèche haut) = rappelle la commande précédente.
- Le **chemin** se lit de gauche à droite : `Documents/TPDL/projet` = dossier dans un dossier.
